# 🌍 SafeTravels

> **A Smart Travel Safety & Assistance Application**

SafeTravels is a travel safety application designed to help travelers plan their journeys, identify safer routes, receive safety-related alerts, discover nearby essential services, and access useful travel recommendations.

The system focuses on improving the travel experience through **location-based services, safety information, real-time notifications, and secure data management**.

---

## 📌 Project Overview

Travelers may face challenges such as unfamiliar locations, unexpected incidents, unsafe areas, and difficulty finding important services while traveling.

**SafeTravels** provides a centralized platform where users can access travel planning and safety-related information before and during their journey.

### 🎯 Main Objective

The main objective of SafeTravels is to provide travelers with useful information and tools that support **safer, easier, and better-informed travel decisions**.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/RAZAN220/SafeTravels.git
```

### 2. Open the Project

```bash
cd SafeTravels
```

### 3. Configure the Database

* Create a MySQL database.
* Import the provided SQL database file.
* Update the database connection settings.

### 4. Run the Application

If using XAMPP:

```text
htdocs/
└── SafeTravels/
```

Start **Apache** and **MySQL** from XAMPP and open the application through your local server.
